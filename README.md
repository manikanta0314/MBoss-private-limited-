# MBOSS Private Limited Website

A responsive static website ready for free hosting.

## Publish free with GitHub Pages
1. Create a GitHub account.
2. Create a new public repository named `mboss.github.io` (replace `mboss` with your GitHub username if needed).
3. Upload `index.html` and `style.css`.
4. Open **Settings → Pages** and select the main branch as the source.
5. GitHub will provide a free `https://USERNAME.github.io/` address.

Before publishing, replace the sample email, phone number and any service/project wording with the company's final details.
